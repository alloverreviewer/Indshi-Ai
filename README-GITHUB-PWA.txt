INDSHI AI — GitHub Pages + PWA Builder package

Upload these files together to the SAME published root folder in your GitHub repository:
- index.html (updated to use favicon.ico/favicon.png and manifest.json)
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
- favicon.png
- favicon.ico
- app-favicon.jpg (in-app logo/splash image)

Deploy with GitHub Pages over HTTPS. Then check these URLs on your deployed site: /manifest.json, /sw.js, /icon-192.png, /icon-512.png, /favicon.ico. If your Pages site is hosted under a repository subpath, use that full Pages URL in PWABuilder.

Note: Do not upload the ZIP itself as the site files; extract it first. Replace existing index.html and manifest.json, and add/replace the icon assets and sw.js.
